# Focus Work 공개 안내 사이트

앱 소개·개인정보처리방침·문의 안내만 제공하는 정적 사이트입니다. 확장 프로그램 소스, 방문 기록, 개인 설정은 포함하지 않습니다.

- 사이트: https://moonseokchoi-kr.github.io/focus-work-site/
- 개인정보처리방침: https://moonseokchoi-kr.github.io/focus-work-site/privacy.html
- 지원: https://moonseokchoi-kr.github.io/focus-work-site/support.html

## 수정과 게시

HTML과 assets/style.css를 수정하고 main 브랜치에 푸시하면 GitHub Pages가 저장소 루트에서 게시합니다. 빌드 도구·npm 패키지·서버·외부 스크립트가 필요하지 않습니다. GitHub Actions의 pages build and deployment 실행 결과와 공개 URL을 확인하세요.

로컬 미리보기: `python3 -m http.server 8080 --bind 127.0.0.1` 후 http://127.0.0.1:8080/ 접속.

정책 변경 시 privacy.html의 최종 수정일과 대상 버전을 함께 확인합니다. Issues는 공개 문의 창구입니다. 민감한 정보를 게시하지 마세요.
