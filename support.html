오류를 알려주실 때

  • 사용 중인 브라우저와 버전, 운영체제, 확장 버전
  • 문제가 발생하기까지의 순서
  • 기대했던 결과와 실제로 나타난 결과
  • 필요한 경우 개인정보를 가린 화면 캡처
문의 내용은 공개됩니다.
방문 기록, 비밀번호, 인증 토큰, 이메일 주소나 비공개 URL은 올리지 마세요. 재현에는 실제 주소 대신 예시 주소를 사용해도 됩니다.

먼저 확인해보세요

차단 중에는 직접 해제할 수 없나요?

집중 시간을 지키기 위해 실행 중인 차단을 직접 종료하는 기능은 제공하지 않습니다. 종료 예정 시각을 확인하고 필요하면 시간을 연장할 수 있습니다.

알림이 보이지 않아요.

브라우저와 운영체제의 알림 권한, 방해 금지 모드를 확인해 주세요. 브라우저 종료나 기기 절전 중의 알림 표시는 보장되지 않습니다.

어떤 페이지든 차단하나요?

등록한 도메인과 하위 도메인의 일반 HTTP·HTTPS 페이지를 대상으로 합니다. 브라우저 내부 화면이나 확장 스토어처럼 브라우저가 보호하는 페이지는 제한될 수 있습니다.

개인정보와 데이터 삭제

기기에 저장하는 정보와 삭제 방법은 개인정보처리방침에서 확인할 수 있습니다. 개발자는 사용자의 로컬 데이터를 원격으로 열람할 수 없습니다. 이메일 문의는 위 주소로 보내실 수 있습니다.
