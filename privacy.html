개인정보처리방침

시행일·최종 수정일: 2026년 11월 7일 · 대상: Focus Work 0.1.0

Focus Work의 운영자는 GitHub 계정 moonseokchoi-kr입니다. 이 문서는 Chrome·Firefox 확장 프로그램과 이 안내 사이트에서의 정보 처리를 구분해 설명합니다.

1. 확장에서 처리하는 정보와 목적

  • 차단 목록: 사용자가 등록한 사이트 도메인을 저장하고 사이트 차단에 사용합니다.
  • 타이머·예약: 사용자가 지정한 시간, 예약 방식, 현재 차단의 시작·종료 시각과 대상 사이트를 저장해 차단과 재시작 후 복구에 사용합니다.
  • 처리 상태: 회차 식별자, 연장 때문에 취소된 예약 회차, 이미 보낸 알림의 식별자를 저장해 중복 실행과 중복 알림을 방지합니다.
  • 주소 자동완성: 입력한 검색어로 브라우저 방문 기록을 최대 100개까지 조회합니다. 일치하는 URL·페이지 제목·최근 방문 시각을 추천 생성에 사용하며, 조회 결과는 일시적으로 메모리에서 처리합니다. 방문 기록 전체나 조회 결과의 사본을 확장 저장소에 저장하지 않습니다. 사용자가 선택해 추가한 도메인은 차단 목록에 저장합니다.
  • 열린 페이지의 주소: 현재 차단 대상인지 판단하고, 이미 열린 탭과 새 탐색에 차단을 적용하는 데 사용합니다. 별도의 탐색 이력이나 페이지 본문을 수집·저장하지 않습니다.

2. 저장 위치와 외부 전송

설정과 실행 상태는 해당 브라우저 프로필의 확장 전용 로컬 저장소(storage.local)에 저장합니다. 계정 가입이나 개발자 서버가 없으며, 확장 자체의 브라우저 간 동기화를 제공하지 않습니다.

확장은 검색어·방문 기록·차단 목록·예약 정보를 개발자나 제3자에게 전송하거나 판매하지 않습니다. 광고, 이용 분석, 원격 오류 수집 도구를 포함하지 않습니다. 알림은 브라우저의 데스크톱 알림 기능을 이용합니다.

방문 기록·주소·설정 정보는 사이트 차단과 주소 자동완성 기능을 제공하는 데만 사용합니다. 광고, 데이터 판매, 개발자의 방문 기록 열람이나 기능과 관계없는 용도로 사용하지 않으며, Chrome 웹스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

3. 보존과 삭제

로컬 설정은 다음 실행과 복구에 필요하므로 브라우저 프로필 안에 보관하며, 정해진 일수 후 모든 데이터를 자동 삭제하는 기능은 없습니다. 차단 목록과 예약은 확장 화면에서 수정·삭제할 수 있습니다. 실행 중인 차단은 시작 당시 상태를 종료 시각까지 유지하므로 목록이나 예약을 삭제해도 즉시 해제되지 않습니다.

전체 확장 데이터를 지우려면 브라우저의 확장 관리 화면에서 Focus Work를 제거하세요. 일반적인 정식 설치에서는 제거 시 확장 로컬 저장소도 삭제됩니다. Firefox에서 개발자용 데이터 보존 설정을 별도로 켜둔 경우나 프로필 백업에는 데이터가 남을 수 있으며, 이 경우 브라우저 설정과 백업도 별도로 관리해야 합니다. 확장을 단순히 비활성화하는 것은 데이터 삭제가 아닙니다.

확장은 브라우저의 원래 방문 기록을 변경하거나 삭제하지 않습니다. 방문 기록은 브라우저의 기록 관리 화면에서 별도로 삭제할 수 있습니다. 운영자는 사용자의 기기에 저장된 확장 데이터를 원격으로 조회하거나 삭제할 수 없습니다.

4. 권한을 사용하는 이유

로컬 저장은 설정 복구에, 방문 기록 접근은 주소 자동완성에, 알람·알림은 예약 실행과 사전 안내에 사용합니다. 웹사이트 접근·스크립트 실행·탐색 이벤트 권한은 사용자가 등록한 도메인에서 주소를 유지하며 차단을 적용하는 데 사용합니다. 네트워크 규칙 권한은 이전 개발 설치에서 남은 차단 규칙을 정리하는 데 사용합니다.

5. 이 사이트와 문의 서비스

이 안내 사이트는 GitHub Pages에서 제공합니다. 자체 쿠키, 외부 폰트, 광고나 분석 스크립트를 추가하지 않습니다. 다만 GitHub는 사이트 제공과 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. GitHub 웹사이트·Issues 이용에는 GitHub 개인정보처리방침이 적용됩니다.

문의는 공개 GitHub Issues에서 받습니다. 작성한 내용은 공개되므로 개인 방문 기록, 인증 정보, 민감한 주소나 개인정보를 올리지 마세요. 문의를 위해 사용자가 직접 게시한 내용은 문제 확인과 답변에 사용됩니다.
